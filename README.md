# 👥 Sistema de Usuários em Python

Sistema de gerenciamento de usuários desenvolvido em Python como projeto de prática dos fundamentos de programação e preparação para desenvolvimento Backend.

## 🚀 Funcionalidades

* 📋 Listar usuários
* 🔎 Buscar usuário
* ➕ Cadastrar usuário
* ✏️ Atualizar usuário
* 🗑️ Excluir usuário
* ✅ Validação de idade
* ⚠️ Tratamento de erros com `try/except`
* 🚫 Prevenção de usuários duplicados
* 🔄 Menu interativo no terminal

## 🛠️ Tecnologias

* Python
* Listas e dicionários
* Funções
* Estruturas condicionais
* Loops
* CRUD
* Tratamento de exceções

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta:

```bash
cd sistema-usuarios-python
```

3. Execute o programa:

```bash
python main.py
```

## 📚 Objetivo

Este projeto foi desenvolvido para praticar conceitos fundamentais de Python e construir uma base para estudos futuros em Backend, incluindo bancos de dados, SQL, APIs REST e FastAPI.
